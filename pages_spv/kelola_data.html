Import Data Cepat (Copy-Paste)

Panduan Copy-Paste:
  1. Buka file Excel Anda.
  2. Pastikan urutan kolom sesuai dengan panduan di bawah kotak teks.
  3. Blok baris data (tanpa *header* tabel) lalu tekan Ctrl + C (Copy).
  4. Klik di dalam kotak teks besar di bawah ini lalu tekan Ctrl + V (Paste).
